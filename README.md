# 📊 Portfolio Optimization & Equity Valuation Analysis (Excel)

## 📌 Project Overview
This project is a comprehensive financial analysis and valuation study combining modern portfolio theory, risk analysis, and intrinsic equity valuation. Using real market data sourced from Bloomberg and FactSet, I constructed and analyzed a four-stock portfolio and performed an in-depth valuation of eBay Inc. using multiple industry-standard valuation frameworks.

The project was completed independently as part of an advanced undergraduate finance course and is designed to mirror analytical work performed in investment management, equity research, and corporate finance roles.

---

## 📈 Portfolio Optimization Analysis

### Assets Included
- Cigna (CI)
- eBay (EBAY)
- Caterpillar (CAT)
- Kimberly-Clark (KMB)

### Methodology
- Calculated historical returns, volatility, and correlations
- Constructed an efficient frontier
- Identified minimum-variance and optimal risk-adjusted portfolios
- Evaluated portfolio performance using:
  - Expected return
  - Standard deviation
  - Beta
  - Sharpe ratio

### Objective
Optimize asset weights to achieve the strongest risk-return tradeoff while demonstrating applied portfolio theory and diversification principles.

---

## 📉 Equity Valuation & Risk Analysis (eBay Inc.)

Following the portfolio optimization, the project transitions into a detailed intrinsic valuation of eBay Inc., selected from the optimized portfolio.

### Valuation Models
- Dividend Discount Model (DDM)
- Free Cash Flow to Firm (FCFF)
- Free Cash Flow to Equity (FCFE)

Each model was built in Excel using forecasted financials, cost of capital assumptions, growth estimates, and terminal value calculations.

---

## 🔍 Scenario & Sensitivity Analysis
To assess valuation robustness, scenario analysis was performed across all valuation models:
- Bull, Base, and Bear cases
- Sensitivity to growth rates
- Sensitivity to discount rates
- Margin assumption impacts

This approach provides a probabilistic view of intrinsic value rather than reliance on a single point estimate.

---

## 📌 Investment Conclusion
Intrinsic value estimates were compared to prevailing market prices to generate a final investment recommendation (Buy / Hold / Sell) supported by quantitative analysis and scenario-weighted outcomes.
